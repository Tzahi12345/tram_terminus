Adds a Turnaround option to the base game underground stop, so tram lines can end there without building a separate turnaround.

Works on new stops and stops you already placed: select the stop, click Configure, and set Turnaround to End 1 or End 2. Pick the end that has no track connected; if nothing changes, try the other end. Trams then turn on a one-way loop past that end: both tracks continue in one wide tunnel, which forks into the loop. Off builds the normal stop.

Options

  • Turnaround: Off, End 1 or End 2
  • Loop Radius: 10 to 30 m (smaller loops need less room)

Removing the mod from a save keeps existing loops working; stops just lose the Turnaround setting.

Source code, feedback and bug reports: github.com/Tzahi12345/tram_terminus

Based on the base game underground stop by Urban Games.
